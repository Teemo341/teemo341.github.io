# Local paper PDFs

将真实论文 PDF 上传到此文件夹，再告诉我对应哪篇论文；我会同步更新网页和两份简历中的链接。

Set that paper's `pdf` field in `content.json` to `papers/filename.pdf`, then rebuild. An explicitly chosen PDF overrides its `url`; clear `pdf` to restore the public URL. A missing file stops the build instead of publishing a broken link. This folder intentionally contains no placeholder PDFs.
